الحالة: يعمل ومُختبَر — صالة وشاشة مطبخ وتذكرة مطبوعة على جهاز واحد، بلا إنترنت. التغليف كـ .exe وربط شاشتين على الشبكة المحلية لم يُبنَ بعد.

ترابيزة تُفتح، طلب يُبعت للمطبخ بتذكرة مطبوعة، ولا حساب قبل ما الأكل يقدم.

6) القواعد

  1. لا إرسال بطلب فاضي.
  2. الإرسال يطبع التذكرة مرة واحدة ويُسجّل ticketPrints؛ إعادة الطبع تُسجَّل وتُزامن.
  3. التحصيل مقفول قبل الإرسال، ومقفول حتى تُقدَّم كل الأصناف — السبب مكتوب تحت الزر.
  4. الإضافة بعد الإرسال تصبح سطراً جديداً (تذكرة تانية) ولا تعدّل المرسل.
  5. لا ترابيزة تُفرَّغ إلا بعد تحصيل كامل.
  6. كل شيء يعمل بلا شبكة، والمزامنة لا تكرر طلباً.

7) معايير القبول

  • ✓فتح ترابيزة وإضافة أصناف وظهور الإجمالي
  • ✓زر التحصيل مقفول قبل الإرسال ومقفول قبل التقديم (مع سبب ظاهر)
  • ✓الإرسال يعلّم السطور «اتبعت» ويطبع تذكرة 80mm
  • ✓المطبخ يحرّك الصنف: يبدأ → جاهز → قدّمني، وتخرج التذكرة بعده
  • ✓التحصيل يغلق الطلب ويعلّم الترابيزة فاضية
  • ✓العمل كامل بعد قطع الشبكة
  • ✓إعادة طباعة تذكرة تُسجَّل كعملية مزامنة

8) كيف يُثبت ذلك

sh tools/run-tests.sh windows
sh tools/setup-browser.sh tools/ui-windows.js

9) خارج النطاق الآن

  • شاشتان على شبكة محلية بمزامنة لحظية (الحالة الحالية: نفس الجهاز).
  • تغليف .exe.
  • شاشة بار.
