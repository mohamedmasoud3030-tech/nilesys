# Nile Systems — منصة الأنظمة والمواقع الجاهزة (نسخة تعليمية)

منصة موحّدة على غرار `marketing-app.runasp.net` (ديمو كود ماتريكس): موقع تسويقي يعرض أنظمة إدارة ومواقع جاهزة، مع **ديمو حقيقي شغال** — نفس تجربة الأصل: حسابات تجربة بضغطة واحدة، بيانات حقيقية بتتحفظ، عربي/إنجليزي بتبديل كامل.

> **الفرق الجوهري عن الموقع الأصلي:** هنا الكود مفتوح بالكامل وبني بأبسط تقنية ممكنة تشتغل فوراً — **Node.js خالص بدون أي مكتبات خارجية** (zero npm dependencies). مفيش `npm install`، ومفيش قاعدة بيانات خارجية: البيانات في ملف JSON واحد سهل الاستبدال بـ SQLite/MySQL لاحقاً.

---

## التشغيل

```bash
cd nilesys
node server.js          # → http://localhost:3000
```

متغيرات البيئة: `PORT` لتغيير البورت (الافتراضي 3000).

## اللي شغال دلوقتي (المرحلة 1)

- **الصفحة الرئيسية** (`/`): هيرو + إحصائيات + منتقي النشاط (اقترح نظام وموقع حسب شغلك) + كروت الأنظمة السبع + المواقع السبعة + قسم برامج الويندوز + جدول مقارنة (أونلاين/ويندوز) + تبديل عربي/إنجليزي كامل مع RTL.
- **نظام الكاشير** (`/systems/pos.html`):
  - دخول بحسابات تجربة بضغطة (صلاحيات مدير/كاشير)
  - نقطة بيع: بحث + مسح باركود + أقسام + شبكة أصناف + سلة كاملة + خصم + كاش/فيزا + فاتورة بإيصال قابل للطباعة
  - فواتير: عرض ومراجعة أي فاتورة
  - مرتجعات (للمدير): اختيار صنف وكمية، المرتجع الجزئي والكلي، ورجوع المخزون
  - ورديات: فتح وردية بنقدية أول المدة، وإغلاق بعدّ الدرج وحساب الفرق
  - تقارير: مبيعات وربح النهارده/الأسبوع، متوسط الفاتورة، الأكثر مبيعاً، مبيعات بالساعة، توزيع طرق الدفع
  - أصناف (للمدير): إضافة/تعديل/حذف مع هامش الربح والمخزون
  - هوية المحل: اسم المحل واللوجو واللون الأساسي (بيتغير فوراً في كل الشاشات)
  - إعادة ضبط الديمو (زي «بيرجع لأصله يوميًا»)

## البنية

```
nilesys/
├── server.js               # سيرفر Node خالص: ملفات ثابتة + API JSON + جلسات كوكيز
├── data/db.json            # قاعدة البيانات (تُنشأ تلقائياً بذور عند أول تشغيل)
└── public/
    ├── index.html          # الصفحة الرئيسية
    ├── systems/pos.html    # نظام الكاشير
    └── assets/
        ├── css/app.css     # نظام تصميم موحّد (RTL-first)
        └── js/
            ├── i18n.js     # قاموس عربي/إنجليزي
            ├── core.js     # أدوات مشتركة (api, toast, modal, تنسيق…)
            ├── home.js     # منطق الصفحة الرئيسية
            └── pos.js      # منطق الكاشير
```

### الـ API

| Method | المسار | الوصف |
|---|---|---|
| POST | `/api/login` | دخول `{system, username, password}` → كوكيز جلسة |
| POST | `/api/logout` | خروج |
| GET | `/api/session` | المستخدم الحالي |
| GET | `/api/bootstrap` | الهوية + الوردية المفتوحة + عدد مبيعات النهارده |
| GET/POST | `/api/products` · `/api/products/:id` | أصناف (تعديل للمدير) |
| POST | `/api/sales` | فاتورة بيع (السعر يُحسب من السيرفر) |
| GET | `/api/sales` · `/api/sales/:id` | الفواتير |
| POST | `/api/returns` | مرتجع من فاتورة (للمدير) |
| POST | `/api/shifts` | `{action: 'open'\|'close'}` |
| GET | `/api/reports/summary?range=today\|week` | تقارير |
| PUT | `/api/branding` | اسم/لوجو/لون المحل |
| POST | `/api/reset` | إعادة ضبط الديمو |

## خطة المراحل الجاية

1. **المرحلة 2:** المخازن والمشتريات + إدارة المطعم (خريطة ترابيزات + شاشة مطبخ لحظية)
2. **المرحلة 3:** العيادة (مواعيد + روشتات) + الموارد البشرية (حضور/مرتبات) + حجز الملاعب + لوحة تحكم المواقع
3. **المرحلة 4:** المواقع السبعة (مطعم، عيادة، عقارات، جيم، موبايلات، ملابس، ملاعب) مرتبطة بلوحاتها
4. **المرحلة 5:** قسم برامج الويندوز + صفحات التحميل + ربط واتساب

## ملاحظات

- الديمو «حي»: أي بيانات بتعملها بتتحفظ في `data/db.json` فعلاً. اضغط «رجّع بيانات الديمو» من شاشة الهوية (مدير) أو امسح الملف وهيعيد البذور تلقائياً.
- عربي/إنجليزي: الزر في أعلى أي شاشة، والاختيار بيتحفظ في المتصفح.
- الأرقام بالإنجليزي (Latin digits) زي الموقع الأصلي، والعملة `ج.م` / `EGP` حسب اللغة.
- المشروع تعليمي توضيحي: التسجيل والصلاحيات مبسّطان (مناسب للديمو، مش production auth).
