# منصة نيل الإنتاجية — مواصفة مشروع

## 1) الغرض

المنتج الحقيقي القابل للبيع والتشغيل عند عميل: محركات بيزنس مُختبَرة فوق PostgreSQL، تعلوها API، ثم واجهات.
هذه هي الوجهة الوحيدة للتقارب؛ البروتوتايب واجهة عرض فقط (انظر `demo-prototype.md`).

## 2) المكونات وملكيتها

| المكون | المسار | يملك |
|---|---|---|
| محرك المعاملات | `engines/transactions/` | بيع · درج · تكلفة · دفع ومرتجعات |
| محرك الكتالوج | `engines/catalog/` | أصناف · مخزون · موردون · طلبات العملاء (leads) |
| محرك الحجوزات | `engines/booking/` | مواعيد وحجوزات (ملاعب/عيادة/مطعم) |
| محرك الأشخاص | `engines/people/` | حضور · إجازات · مرتبات |
| محرك المنصة | `engines/platform/` | دخول · أدوار · مستأجر · هوية بصرية |
| قاعدة البيانات | `engines/db/` (Drizzle + migrations) | مخطط وترحيلات PostgreSQL |
| الـAPI | `apps/api/` | HTTP فوق المحركات (الحالة: نطاق الكاشير أساسًا) |

## 3) القواعد الملزمة

1. المحرك أولًا ثم الـAPI ثم الشاشة — لا شاشة فوق غير محرك (قرار التقارب 2026-10-21).
2. المال بدقة عشرية، والدفاتر append-only، وRLS عازل للمستأجرين (انظر `../../FINANCIAL_RULES.md` و`../../DECISIONS.md`).
3. كل قاعدة بيزنس لها اختبار على PostgreSQL حقيقي حيث تمس المال أو التزامن.

## 4) الحالة الصادقة (2026-10-21)

| البند | الحالة |
|---|---|
| المحركات والاختبارات | مبنية؛ سجل الإثبات في `../../STATUS.md` |
