# نيل تقارير (ويندوز) — مواصفة مستقلة

> الحالة: **يعمل ومُختبَر** — يقرأ ما حفظته البرامج الأخرى على نفس الجهاز ويعرضه بلا تزييف.
> التغليف كـ `.exe` وتقارير متعددة الفروع لم تُبنَ بعد.

## 1) الغرض في سطر

المدير يفتح شاشة واحدة فيرى بيع اليوم وقيمة المخزون والحضور — وكل رقم بجانبه مصدره.

## 2) المستخدمون

| المستخدم | يدخل بـ | يقدر يعمل | لا يقدر |
| --- | --- | --- | --- |
| مدير الفرع | بلا تسجيل (جهاز المدير) | مؤشرات · تقرير A4 · CSV · قراءة ملخص الخادم | تعديل بيانات البرامج |

## 3) الشاشات

| الشاشة | ماذا فيها |
| --- | --- |
| لوحة المؤشرات | بيع اليوم · إجمالي المبيعات · قيمة المخزون · الحضور · المطعم |
| تقرير A4 | صفحة واحدة قابلة للتوقيع + CSV |
| مصادر البيانات | أي برنامج موصول على الجهاز · الملخص الواصل للخادم |
| المزامنة | الطابور وآخر مزامنة |

## 4) نموذج البيانات

يقرأ من `nile.os.cashier.v1` · `nile.os.stock.v1` · `nile.os.kitchen.v1` · `nile.os.attendance.v1`
(نفس الجهاز/المتصفح)، ويكتب فقط عملياته: `report.print` · `month.export`.

## 5) الواجهات

```
GET  /api/windows/summary    ← ما وصل للخادم من الأجهزة (بمفتاح الجهاز)
```

## 6) القواعد

1. كل رقم بجانبه برنامجه؛ البرنامج غير الموصول يُقال عنه «لا بيانات على الجهاز».
2. الصفر يُعرض صفراً لا شرطة ولا رقم مخترع.
3. التقرير A4 صفحة واحدة فيها المصدر وتوقيعان.
4. CSV بترميز UTF-8 BOM.
5. لا يعدّل بيانات البرامج الأخرى — قراءة فقط.
6. الطباعة والتصدير يُسجَّلان كعمليات مزامنة.

## 7) معايير القبول

- [x] لوحة المؤشرات تعرض أرقام البرامج الموصولة على الجهاز
- [x] برنامج غير موصول يظهر «لا بيانات» لا رقماً وهمياً
- [x] تقرير A4 يحتوي البنود الأساسية والتوقيعين والمصدر
- [x] تصدير CSV يفتح بترميز عربي سليم (BOM)
- [x] قراءة ملخص الخادم بمفتاح الجهاز، والفشل يُقال صراحةً ويعمل البرنامج بدونه
- [x] بيانات البرامج الأخرى لا تتغيّر من داخل التقارير
- [x] الطباعة تُسجَّل كمزامنة بلا تكرار

## 8) كيف يُثبت ذلك

```sh
sh tools/run-tests.sh windows
sh tools/setup-browser.sh tools/ui-windows.js
```

## 9) خارج النطاق الآن

- تقارير فترات طويلة وأرشيف سنين (السجل الحالي لآخر 8000 عملية على الخادم).
- تعدُّد الفروع ومقارنتها.
- تغليف `.exe`.
