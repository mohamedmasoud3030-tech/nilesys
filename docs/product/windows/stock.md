# نيل مخازن (ويندوز) — مواصفة مستقلة

> الحالة: **يعمل ومُختبَر** — جرد واستلام وملصقات على جهاز المخزن، بلا إنترنت.
> التغليف كـ `.exe` لم يُبنَ بعد.

## 1) الغرض في سطر

رصيد المخزن يطابق الرف: عدّ فعلي بفرق مكتوب السبب، استلام من مورد، وملصق باركود يُطبع من الجهاز.

## 2) المستخدمون

| المستخدم | يدخل بـ | يقدر يعمل | لا يقدر |
| --- | --- | --- | --- |
| أمين المخزن | بلا تسجيل (جهاز المخزن) | صنف · جرد · استلام · ملصق · مزامنة | تعديل حركة قديمة |
| الخادم | مفتاح الجهاز | استقبال الحركات ورفض المكرر | تعديل رصيد الجهاز |

## 3) الشاشات

| الشاشة | ماذا فيها |
| --- | --- |
| الأصناف | كود · اسم · رصيد · حد تنبيه · تكلفة · سعر · ملصق |
| الجرد | الرصيد الدفتري مقابل المعدود · الفرق · سبب إلزامي عند الفرق |
| استلام | مورد/إذن · سطور كمية · تحديث الرصيد |
| الحركات | كل تعديل رصيد بنوعه وسببه ومفتاحه |
| المزامنة | الطابور وآخر مزامنة |

## 4) نموذج البيانات (على الجهاز)

| المفتاح | الحقول |
| --- | --- |
| `items[]` | `id` · `code` · `name` · `unit` · `qty` · `cost` · `price` · `min` |
| `moves[]` | `id` · `at` · `type` (`count`/`in`) · `itemId` · `code` · `qty` · `reason` · `ref` |
| `counts[]` | `id` · `at` · `rows[]` (`book` · `counted` · `diff` · `reason`) |
| `receipts[]` | `id` · `at` · `supplier` · `lines[]` |

## 5) الواجهات

```
POST /api/windows/sync      { program:'stock', ops:[…] }
GET  /api/windows/summary
```

## 6) القواعد

1. أي فرق في الجرد بلا سبب مكتوب → الجرد لا يُحفظ ويُقال أي صنف ناقص السبب.
2. الرصيد لا يصير سالباً.
3. كود الصنف فريد ومطلوب (بدونه لا ملصق)، والكود المستخدم يُرفض.
4. ملصق الباركود **Code39 حقيقي** يُرسم من جدول الترميز لا شكلاً عشوائياً.
5. الاستلام لا يقبل كمية صفر أو سالبة.
6. كل حركة لها مفتاح فريد، والمزامنة لا تضاعف الحركة.
7. قيمة المخزون = مجموع (الرصيد × التكلفة) — لا تُقدَّر.
