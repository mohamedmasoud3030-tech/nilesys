# نيل كاشير (ويندوز) — مواصفة مستقلة

> الحالة: **يعمل ومُختبَر** — البرنامج يفتح في المتصفح وكل عمله محلي، ويعمل بعد قطع الشبكة كاملاً.
> التغليف كـ `.exe` (Electron) لم يُبنَ بعد، ولا يوجد زر تحميل يدّعي غير ذلك.

## 1) الغرض في سطر

كاشير يشتغل على جهاز المحل بلا إنترنت: يبيع، يطبع إيصالاً، ويقفل ورديته بفرق محسوب — ويزامن لاحقاً بلا فاتورة مكررة.

## 2) المستخدمون

| المستخدم | يدخل بـ | يقدر يعمل | لا يقدر |
| --- | --- | --- | --- |
| كاشير الجهاز | بلا تسجيل (جهاز المحل) | بيع · إيصال · فتح/إغلاق وردية · مزامنة | — |
| الخادم | مفتاح الجهاز `x-nile-device` | استقبال الدفعات ورفض المكرر | تعديل بيانات الجهاز |

## 3) الشاشات

| الشاشة | ماذا فيها |
| --- | --- |
| بيع | شبكة الأصناف بالبحث · سلة بأزرار كمية · الإجمالي والضريبة · تحصيل (F2) |
| الفواتير | كل فاتورة على الجهاز · إعادة طباعة الإيصال |
| الوردية والدرج | فتح بدرج البداية · المتوقع · المعدود · الفرق |
| المزامنة | الطابور · آخر مزامنة · رقم الجهاز · إعادة ضبط العرض |

## 4) نموذج البيانات (على الجهاز — `localStorage`)

| المفتاح | الحقول |
| --- | --- |
| `settings` | `storeName` · `branch` · `taxRate` |
| `products[]` | `id` · `code` · `name` · `price` · `cost` · `stock` |
| `sales[]` | `id` · `no` · `at` · `shiftId` · `items[]` · `subtotal` · `total` · `method` · `paid` · `change` |

## 5) الواجهات

```
POST /api/windows/sync       { program:'cashier', device, ops:[{key,type,at,amount,payload}] }
GET  /api/windows/summary    ← ملخص ما وصل من الأجهزة
GET  /api/windows/programs   ← الخمسة برامج وحالة كل واحد
```

## 6) القواعد

1. السلة الفاضية لا تُحصَّل، والزر مقفول لا يخفي السبب.
2. لا بيع نقدي بلا وردية مفتوحة.
3. المدفوع أقل من المطلوب → زر التحصيل مقفول و«الباقي» يقول «ناقص».
4. الفاتورة تُحفظ على الجهاز **قبل** الطباعة، وتدخل طابور المزامنة بمفتاح فريد.
5. الخادم يتذكّر المفتاح: إعادة إرسال نفس الفاتورة تعود `duplicates` ولا تُسجَّل مرتين.
6. إغلاق الوردية يحسب `متوقع = بداية + مبيعات نقدية` والفرق `معدود − متوقع`.
7. الربح لا يُخترع: التكلفة محفوظة للصنف، ولا يُعرض ربح بلا تكلفة.

## 7) معايير القبول

- [x] بيعة كاملة من الشاشة: صنف → سلة → تحصيل → فاتورة في القائمة
- [x] لا تحصيل بسلة فاضية ولا بمدفوع ناقص
- [x] إيصال 80mm يحتوي بنود الفاتورة والإجمالي والباقي
- [x] الوردية تُفتح، ومبيعاتها النقدية تُحسب في المتوقع، والفرق يظهر بعد الإغلاق
- [x] البيع يعمل بعد قطع الشبكة (وضع أوفلاين حقيقي في الاختبار)
- [x] المزامنة بعد رجوع الشبكة تفرّغ الطابور، وإعادة إرسال نفس الدفعة لا تضاعف شيئاً (409/duplicates)
- [x] الخادم يرفض مفتاح جهاز غير معروف (401)

## 9) خارج النطاق الآن

- تغليف `.exe` وتوقيع التثبيت (يحتاج بناء على ويندوز).
- طابعة حرارية عبر USB (الطباعة حالياً من المتصفح بنفس مقاس 80mm).
- تعدُّد الكاشيرات على جهاز واحد.
