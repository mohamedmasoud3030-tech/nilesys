# نيل مطعم (ويندوز) — مواصفة مستقلة

> الحالة: **يعمل ومُختبَر** — صالة وشاشة مطبخ وتذكرة مطبوعة على جهاز واحد، بلا إنترنت.
> التغليف كـ `.exe` وربط شاشتين على الشبكة المحلية لم يُبنَ بعد.

## 1) الغرض في سطر

ترابيزة تُفتح، طلب يُبعت للمطبخ بتذكرة مطبوعة، ولا حساب قبل ما الأكل يقدم.

## 2) المستخدمون

| المستخدم | يدخل بـ | يقدر يعمل | لا يقدر |
| --- | --- | --- | --- |
| كاشير/ويتر | بلا تسجيل | ترابيزة · طلب · إرسال · تحصيل | تحصيل قبل التقديم |
| شيف | نفس الجهاز | تحريك حالة الصنف (يبدأ/جاهز/قدّمني) | تحصيل |

## 3) الشاشات

| الشاشة | ماذا فيها |
| --- | --- |
| الترابيزات | 8 ترابيزات بحالتها (فاضية/طلب مفتوح/نشطة) وإجمالي كل واحدة |
| الطلب | قائمة · سلة · إرسال للمطبخ · تحصيل وإغلاق |
| المطبخ | تذاكر مفتوحة بعمرها بالدقائق · أزرار الحالة |
| الطلبات | كل الطلبات وحالتها · إعادة طباعة تذكرة |
| المزامنة | الطابور وآخر مزامنة |

## 4) نموذج البيانات

| المفتاح | الحقول |
| --- | --- |
| `tables[]` | `id` · `name` · `seats` |
| `orders[]` | `id` · `no` · `tableId` · `at` · `sentAt` · `status` (`open`/`paid`) · `items[]` · `ticketPrints` · `lastPrintAt` · `total` · `method` |
| `items[]` | `id` · `menuId` · `name` · `price` · `qty` · `station` · `state` (`new`/`cooking`/`ready`/`served`) |

## 5) الواجهات

```
POST /api/windows/sync   { program:'kitchen', ops:[…] }
```

## 6) القواعد

1. لا إرسال بطلب فاضي.
2. الإرسال يطبع التذكرة مرة واحدة ويُسجّل `ticketPrints`؛ إعادة الطبع تُسجَّل وتُزامن.
3. التحصيل مقفول قبل الإرسال، ومقفول حتى تُقدَّم كل الأصناف — السبب مكتوب تحت الزر.
4. الإضافة بعد الإرسال تصبح سطراً جديداً (تذكرة تانية) ولا تعدّل المرسل.
5. لا ترابيزة تُفرَّغ إلا بعد تحصيل كامل.
6. كل شيء يعمل بلا شبكة، والمزامنة لا تكرر طلباً.

## 7) معايير القبول

- [x] فتح ترابيزة وإضافة أصناف وظهور الإجمالي
- [x] زر التحصيل مقفول قبل الإرسال ومقفول قبل التقديم (مع سبب ظاهر)
- [x] الإرسال يعلّم السطور «اتبعت» ويطبع تذكرة 80mm
- [x] المطبخ يحرّك الصنف: يبدأ → جاهز → قدّمني، وتخرج التذكرة بعده
- [x] التحصيل يغلق الطلب ويعلّم الترابيزة فاضية
- [x] العمل كامل بعد قطع الشبكة
- [x] إعادة طباعة تذكرة تُسجَّل كعملية مزامنة

- تغليف `.exe`.
