# لوحة المواقع — مواصفة مستقلة

> الحالة: **لم يُبنَ بعد**. المواقع السبعة نفسها تعمل كصفحات؛ اللوحة التي تديرها لم تُبنَ.

## 1) الغرض في سطر

تعرف أي موقع شغّال، كم زائر، وكم رسالة جات منه — وتعدّل كلامه من مكان واحد.

## 2) المستخدمون

| المستخدم | يدخل بـ | يقدر يعمل | لا يقدر |
| --- | --- | --- | --- |
| مدير الموقع | `admin` | كل شيء: حالات · محتوى · رسائل · تقارير | — |
| مدير نشاط | `manager` | يرى موقعه ورسائله فقط | تعديل مواقع أخرى |

## 3) الشاشات

| الشاشة | ماذا فيها |
| --- | --- |
| نظرة عامة | الأنظمة (يعمل/مخطط) · المواقع السبعة · الرسائل الجديدة اليوم |
| المواقع | اسم · رابط · حالة · عنوان · تليفون · واتساب · نشط/موقوف |
| المحتوى | عنوان الصفحة · وصف · صورة · يُحدَّث من هنا بلا كود |
| الرسائل | اسم · موبايل · رسالة · المصدر · جديدة/تم الرد/مغلقة |
| الزيارات | عدد الزيارات لكل موقع باليوم |
| التقارير | أكثر المواقع جذباً · نسبة الرد · رسائل بلا رد |

## 4) نموذج البيانات

| المجموعة | الحقول |
| --- | --- |
| `sites` | `id` · `slug` · `name` · `status` (`live`/`coming`) · `url` · `headline` · `phone` · `whatsapp` · `active` |
| `siteLeads` | `id` · `siteSlug` · `name` · `phone` · `message` · `status` (`new`/`replied`/`closed`) · `at` |
| `siteViews` | `siteSlug` · `date` · `count` |

## 5) الواجهات

```
GET  /api/sites                 ← سبعة مواقع بحالتها الحقيقية
POST /api/sites/:slug/lead      { name, phone, message }    ← عام، بلا تسجيل دخول
GET  /api/sites/leads?status=
POST /api/sites/leads/:id/status { status }
PUT  /api/sites/:slug           { headline, phone, whatsapp, active }   (admin)
POST /api/sites/:slug/view      ← عدّاد زيارة، مرة لكل جلسة
GET  /api/sites/summary
```

## 6) القواعد

1. كل موقع يقول حالته الحقيقية؛ لا «قريباً» على شيء يعمل ولا «يعمل» على شيء لم يُبنَ.
2. الرسالة تُحفظ مع مصدرها، وموبايل مكرر في نفس الموقع لا يفتح رسالة مكررة قبل 24 ساعة.
3. الرسالة «مغلقة» لا تعود «جديدة».
4. `admin` يرى الكل؛ مدير نشاط يرى موقعه فقط (403 لغيره).
5. العدّاد لا يُضاعف زيارة نفس الجلسة في نفس اليوم.

## 7) معايير القبول

- [x] سبعة مواقع بحالة صادقة، واثنان على الأقل `live` مع رابط يعمل
- [x] رسالة من صفحة موقع عامة تُحفظ وتظهر في اللوحة
- [x] نفس الموبايل مرتين في 24 ساعة → رسالة واحدة
- [x] مدير نشاط يطلب موقعاً آخر → 403
- [x] رسالة مغلقة لا ترجع جديدة (409)
- [x] زيارة مكررة من نفس الجلسة لا تُحسب مرتين
- [x] اللوحة تعرض عدد الأنظمة العاملة من سجل الأنظمة نفسه لا من رقم مكتوب

## 8) كيف يُثبت ذلك

```sh
sh tools/run-tests.sh sites                    # المحرّك وواجهته البرمجية — 10/10
sh tools/setup-browser.sh tools/ui-sites-dash.js   # اللوحة في متصفح حقيقي — 24/24
```

**أين الإثبات:** `tests/sites.test.js` (SETUP + S-01…S-09) · `tools/ui-sites-dash.js` (24 فحصاً).

| المعيار | الدليل |
| --- | --- |
| سبعة مواقع بحالة صادقة | S-01: قائمة السبعة كلها ترد 200، والأزياء `live` والجيم `coming` — مطابقة لشارة صفحته |
| رسالة عامة تُحفظ | S-02: `POST /api/sites/fashion/lead` بلا تسجيل دخول → 201، وتظهر في `/api/sites/leads` باسم الموقع |
| موبايل مكرر | S-03: الطلب الثاني → 200 مع `duplicate:true` ونفس مُعرِّف الرسالة، وصف واحد في اللوحة |
| مدير نشاط مقيَّد | S-05: يرى `fashion` وحده، وتعديل رسالة/محتوى موقع آخر → 403، ومستخدم نظام آخر → 403 |
| رسالة مغلقة | S-06: مغلقة → «تم الرد» → 409، ومغلقة → مغلقة → 409، وحالة غير معروفة → 400 |
| زيارة واحدة للجلسة | S-07: نفس الكوكي → `counted:false` والعدد ثابت؛ جلسة أخرى → +1 ويظهر في اللوحة |
| الأنظمة من السجل | S-08: العدد يطابق `public/data/systems.json` المولَّد من `docs/product/systems/*.md` |
| المحتوى والحالة | S-09: تعديل العنوان يحفظ ويظهر، وكتابة `status` من اللوحة → 400 (تُقرأ من الصفحة)، والإيقاف لا يحذف |

**تغطية الواجهة (24 فحصاً):** الدخول ورفض حساب نظام آخر · 7 بطاقات · رقم الأنظمة من السجل · الحالات الصادقة ·
نموذج الرسالة في الصفحة العامة (ورفض موبايل غير صالح) · تكرار الموبايل · الرسالة تظهر في اللوحة ·
«تم الرد» ثم «إغلاق» على صفّ بعينه وما بعده لا إجراء · الزيارات والتقارير بلا NaN · تعديل المحتوى يظهر فوراً ·
مدير النشاط: موقع واحد، بلا تعديل، ورسائل موقعه فقط · صفر أخطاء JavaScript.

**كيف يعمل العدّاد والنموذج على الصفحات العامة:** `public/assets/js/site-lead.js` يُحقن في كل صفحة تحمل
`<body data-site="slug">`، ويسجّل زيارة واحدة لكل جلسة (`nile_vid`) في اليوم، ويرسل الرسالة إلى
`POST /api/sites/:slug/lead` — بلا تسجيل دخول وبلا مكتبات.

## 9) خارج النطاق الآن

- محرّر صفحات مرئي (drag & drop).
- تحليلات تفصيلية (مصادر الزيارة، مسارات).
- إشعار واتساب تلقائي على الرسالة.
